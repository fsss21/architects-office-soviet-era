# Памятники советской эпохи

## Краткое описание ПО

Интерактивный киоск зала памятников советской эпохи музея «Уткина дача». Посвящён развитию советского монументального искусства 1930–1980-х гг., смене идеологических приоритетов, художественным методам и роли конкурсной системы. Включает каталог скульптур зала.

## Сценарий работы ПО

### Стартовый экран

Полноэкранная заставка. Касание экрана открывает главное меню.

### Главное меню

Заголовок «Памятники советской эпохи». Карусель из четырёх тем:

- Хронология развития советского монументального искусства 1930–1980-х гг.
- Смена идеологических приоритетов: от революции к культуре, от культуры к войне
- Эволюция художественных методов и материалов
- Роль конкурсной системы в создании памятников

Кнопки:

- **Подробнее** — экран темы (SubMenu) со всеми четырьмя темами на линии прогресса
- **Перейти в каталог скульптур** — каталог

### Экран темы (SubMenu)

Текст и фото по выбранной теме.  
**Назад** → главное меню.  
**Перейти в каталог** → каталог советских памятников.

### Каталог и карточка объекта

Просмотр объектов зала с фильтрами и карточками. **Назад** → главное меню.
